# Script generation

## Input boundary

The user supplies the source script. Do not conduct web research or add claims that are not supported by that script.

Convert the source into an alternating dialogue for the character pair selected by the user. Preserve every important beat in the same order. If a sentence contains several distinct claims, split those claims across exchanges so the response to each claim feels natural.

## Peter and Stewie roles

- Peter is the enthusiastic explainer. His lines should be simple, punchy, and focused on one idea at a time.
- Stewie is the skeptical questioner. His replies should react to Peter's immediately preceding claim and lead naturally into Peter's next answer.

## Rick and Morty roles

- Rick is the confident, impatient explainer. His lines should be sharp, direct, and focused on one idea at a time.
- Morty is the overwhelmed but curious questioner. His replies should react to Rick's immediately preceding claim and lead naturally into Rick's next answer.

## Dialogue rules

- Use 6–12 exchanges, or retain the source's required structure if the user explicitly requests it.
- Alternate the selected characters strictly. The final line belongs to the selected second character: Stewie or Morty.
- Each line must reply directly to the line before it.
- The selected explainer, Peter or Rick, must not combine multiple major beats into one line.
- The selected questioner, Stewie or Morty, should react to a specific preceding claim and ask the question that naturally unlocks the next point.
- Do not add facts, features, pricing, or promises absent from the source script.
- Do not force catchphrases or jokes. Use them only when the preceding line sets them up naturally.
- Do not use "innovative", "leverage", "cutting-edge", or "game-changing".
- The final questioner line should retain the supplied call to action. If the source contains no CTA, use `Comment "[KEYWORD]" and I'll send you the link`, selecting a simple topic-related keyword.

## Emotion tags

Every dialogue line begins with one of these tags only:

- `(excited)` for the selected explainer, and for the selected questioner when impressed or delivering the CTA
- `(surprised)` for the selected questioner's skeptical reactions and questions

The Creatorberry promotional message is never included in dialogue generation.

## Caption

Create an Instagram caption after the dialogue is generated:

1. Put the CTA line first.
2. Explain the source script's main value in short, clear, story-like paragraphs.
3. Repeat the identical CTA line last.

The caption must only describe claims supported by the source script. Do not include the separate Creatorberry promotional message unless the user specifically asks for it in the caption.
